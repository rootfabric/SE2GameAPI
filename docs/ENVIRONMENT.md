# Проверка окружения — 2026-11-09

> Обновление после реализации: диагностический плагин 0.0.1 успешно собран и загружен через переносимый Pulsar 2.4.3 на .NET 10.0.14. Проверено увеличение heartbeat в главном потоке SE2. SDK 10.0.403 и Pulsar установлены локально в `artifacts/tools`. Подробности и повторный запуск — в README. Ниже сохранён исходный отчёт до подготовки окружения.

## Подтверждено локально

- Игра: `D:\SteamLibrary\steamapps\common\SpaceEngineers2\Game2\SpaceEngineers2.exe`.
- Steam App ID: `1133870`; установленный Build ID: `26163761`.
- `SpaceEngineers2.runtimeconfig.json`: `net9.0`, Microsoft.NETCore.App и Microsoft.WindowsDesktop.App 9.0.0.
- Установлены соответствующие runtime 9.0.21. В выводе `dotnet --list-sdks` только SDK 8.0.400.
- Команда `python --version` возвращает Python 3.11.8.
- Сборки Game2 и VRage присутствуют в папке игры и доступны для исследования API.
- В проверенных каталогах AppData, Downloads, Desktop, C:\tools и Game2 Pulsar не обнаружен. Это не полный поиск по всем дискам.
- Локальный TCP-порт 6379 не прослушивается. Доступность удалённого Redis не проверялась.

## Практический запуск

Игра запущена через Computer Use. Первый процесс передал запуск Steam и завершился штатно, поскольку прямому запуску не хватало App ID. Steam запустил новый процесс; затем обнаружено окно с заголовком `Space Engineers 2`.

Журнал `%APPDATA%\SpaceEngineers2\Temp\Logs\SpaceEngineers2_261109_000443_055_7760.log` содержит завершение загрузки приложения (`LOADING_TIME_FULL|Application`) и запуск render loop. Это подтверждает запуск приложения, но не загрузку тестового мира.

Захват окна через Computer Use не удался: `FrameArrived timed out: timed out waiting on channel`; после повторного выбора окна и активации — `window capture timed out: timed out waiting on channel`. Поэтому главное меню визуально не проверено, действия внутри мира не выполнялись. Игра оставлена запущенной.

## Проверка плана

Текущий [шаблон CometWorks](https://github.com/CometWorks/client2-plugin-template) указывает .NET 10 SDK, Python 3.12+ и запуск через Pulsar Modern. Локальная игра пока использует .NET 9. Нельзя автоматически считать этот шаблон совместимым с установленной сборкой: сначала проверить соответствующие версии загрузчика и шаблона либо необходимость обновления игры.

Исходный план сохранён без изменений. Перечисленные в нём типы идентификаторов, методы доступа к блокам и совместимость LampDevice ещё требуют проверки. Пример Python в исходном тексте потерял переводы строк; перед использованием его нужно восстановить.

## Порядок дальнейшей проверки

1. Выбрать совместимые версии игры, Pulsar Modern, шаблона и SDK.
2. Собрать и загрузить минимальный плагин с записью версии и heartbeat в локальный журнал.
3. Создать отдельный тестовый мир; подтвердить доступ к гридам и фактическое управление одной лампой без Redis.
4. Подключить Redis и проверить команды и ACK с одинаковым requestId.
5. Выполнить восемь критериев приёмки из плана, включая восстановление после перезапуска.

Итог: запуск игры подтверждён процессом, окном и журналом; возможность полного автоматизированного тестирования плагина пока не подтверждена. Плагин в рамках этой проверки не создавался и не загружался.
